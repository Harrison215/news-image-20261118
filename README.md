An offline, deterministic illustrated summary of world news reported on Wednesday, 18 November 2026.

## Run

With Node.js 22 or later, the program writes `entry.png` to `/output`. Outside the Make.fun runner, set `MAKEFUN_OUTPUT_DIR` to a writable directory.

The entry uses only Node.js built-in modules and makes no network requests.

## News represented

- APEC leaders in Shenzhen and Xi Jinping's call for open trade and equitable growth.
- Small island nations calling for stronger climate action at COP31 in Antalya.
- Mary Peltola's Alaska Senate win and the resulting 56–44 Democratic majority.
- Asian markets falling as AI-linked shares swung.

Sources: Associated Press reports published on 18 November 2026.
